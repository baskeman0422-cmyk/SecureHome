# SecureHome - エコキュート適正価格診断センター

## プロジェクト概要
訪問販売による高額被害を未然に防ぎ、エコキュートの適正価格での普及を目指すランディングページアプリケーションです。

## 技術スタック
- React + TypeScript
- Vite
- Tailwind CSS
- Lucide React (アイコン)

## コンポーネント構成

### `components/` ディレクトリ

#### Header.tsx
- **説明**: ページ上部の固定ヘッダー
- **機能**: 
  - サイトロゴとタイトル表示
  - 訪問販売トラブルの警告バー
  - LINE診断ボタン（デスクトップ版）
  - 登録電気工事業者番号の表示

#### Hero.tsx
- **説明**: メインビジュアルセクション（ファーストビュー）
- **機能**:
  - 大きなキャッチコピーとCTA（Call to Action）
  - アニメーション付きの背景エフェクト
  - 「ちょっと待った！」の吹き出し警告
  - 信頼バッジの表示
  - スマホとLINEアプリのモックアップ画像

#### Warning.tsx
- **説明**: 訪問販売の悪質な手口を警告するセクション
- **機能**:
  - 訪問販売の具体的な手口をカード形式で表示
  - 危険度を示すビジュアルデザイン（黄色/黒のストライプ）
  - スクロール連動のアニメーション効果

#### Comparison.tsx
- **説明**: 価格比較を視覚化するセクション
- **機能**:
  - 高額見積もりと適正価格の比較チャート
  - 価格差（最大60万円）の強調表示
  - 拡大モーダル機能付き
  - 差額の内訳説明（利益・マージン・適正価格）

#### Features.tsx
- **説明**: サービスの特徴・強みを紹介するセクション
- **機能**:
  - 4つの主要な強み（POINT）をカード形式で表示
  - 各カードに背景画像とアイコン
  - スクロールに応じた拡大・強調エフェクト
  - 中央に来たカードを自動的にハイライト

#### Flow.tsx
- **説明**: 無料診断の利用手順を説明するセクション
- **機能**:
  - 4ステップの流れを視覚化
  - アイコンとステップ番号付きカード
  - スマホのモックアップ画像
  - 「最短5分」などの強調ポイント

#### FAQ.tsx
- **説明**: よくある質問のアコーディオンセクション
- **機能**:
  - 質問クリックで回答を展開/折りたたみ
  - 質問と回答のQ&A形式
  - スムーズな開閉アニメーション

#### Footer.tsx
- **説明**: ページ下部のフッター
- **機能**:
  - 会社情報（セキュアホーム）
  - 本店・千葉支店の所在地
  - 営業時間・定休日
  - 登録電気工事業者番号
  - 特定商取引法・プライバシーポリシーへのリンク

#### StickyFooter.tsx
- **説明**: モバイル専用の固定フッターボタン
- **機能**:
  - 画面下部に固定されたLINE診断ボタン
  - モバイルのみ表示（`md:hidden`）
  - シャインエフェクトとシェイクアニメーション
  - 直接LINEへのリンク

#### Legal.tsx
- **説明**: 特定商取引法に基づく表記ページ
- **機能**:
  - 事業者情報の詳細表示
  - 商品・料金・支払い方法
  - キャンセルポリシー
  - 引き渡し時期
  - トップページへ戻るボタン

#### PrivacyPolicy.tsx
- **説明**: プライバシーポリシー（個人情報保護方針）ページ
- **機能**:
  - 個人情報の取得・利用目的
  - 第三者提供・管理体制
  - 開示請求・問い合わせ先
  - トップページへ戻るボタン

## フォルダ構成

```
/
├── components/          # UIコンポーネント
├── hooks/              # カスタムフック
│   └── useIntersectionObserver.ts  # スクロール監視フック
├── server/             # バックエンドサーバー
│   ├── server.js       # Node.jsサーバー
│   └── public/         # 静的ファイル
├── constants.ts        # 定数定義（FAQ、TACTICS、STRENGTHSなど）
├── types.ts           # TypeScript型定義
├── App.tsx            # メインアプリケーション
├── index.tsx          # エントリーポイント
└── vite.config.ts     # Vite設定

```

## 開発環境のセットアップ

### 必要な環境
- Node.js (v18以上推奨)
- npm または yarn

### インストール

```bash
# 依存パッケージのインストール
npm install

# 開発サーバーの起動
npm run dev
```
